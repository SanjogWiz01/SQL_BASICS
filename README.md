## ✨ About This Repository

This repository contains **well-organized, hands-on SQL scripts and examples** to help you master relational databases. 

Perfect for beginners, students, and anyone preparing for data-related interviews or projects.

Each file/folder focuses on a specific SQL topic with clear explanations and runnable queries.

---

## 📁 Repository Structure

| Folder / File                  | Topic Covered                              |
|--------------------------------|--------------------------------------------|
| **01_Basics**                  | DDL, DML, Data Types, Basic Queries       |
| **02_Queries**                 | SELECT, WHERE, ORDER BY, LIMIT            |
| **03_Joins**                   | INNER, LEFT, RIGHT, FULL, CROSS Joins     |
| **04_Aggregation**             | GROUP BY, HAVING, Aggregate Functions     |
| **05_Subqueries**              | Nested Queries & CTEs                     |
| **06_Advanced**                | Window Functions, Indexes, Views          |
| **Practice_Database**          | Sample schema + data for practice         |
| **Exercises**                  | Challenge problems with solutions         |
